# Руководство по подключению ИИ на Бэкенде (Google Gemini)

## Архитектура интеграции

В проекте реализована безопасная enterprise-архитектура без отображения ключей в веб-интерфейсе:

```
[ Браузер (Сотрудник / Служба EX) ]
                 │
                 │ HTTP REST (без секретов и ключей)
                 ▼
    ┌──────────────────────────┐
    │     PYTHON BACKEND       │  <─── .env (GEMINI_API_KEY)
    │       (server.py)        │
    └────────────┬─────────────┘
                 │
       ┌─────────┴─────────┐
       ▼                   ▼
gemini-1.5-flash      gemini-1.5-pro
(Приемная Айгерим)   (Аналитика Правления)
```

1. **Ключ API изолирован**: переменная `GEMINI_API_KEY` хранится исключительно в файле `.env` на сервере и никогда не попадает в браузер клиентов.
2. **Разделение моделей по нагрузке**:
   - **`gemini-1.5-flash`** (эндпоинт `/api/ai/intake`) — сверхбыстрый отклик (< 1 сек) для пошагового диалога с сотрудником, выявления деталей, проверки Conflict Guard и формулирования фабулы по ТК РК (ст. 108, 182).
   - **`gemini-1.5-pro`** (эндпоинт `/api/ai/analytics`) — модель с окном контекста 2 000 000 токенов для глубокого многофакторного анализа, расчета корреляций с внешними CSV и составления докладов для Правления.
3. **Отказоустойчивость (Graceful Fallback)**: если бэкенд выключен или ключ еще не вставлен, платформа автоматически переключается на встроенный детерминированный эвристический движок — интерфейс никогда не ломается.

## Быстрый старт за 3 шага

### Шаг 1. Получите API-ключ Gemini (бесплатно)
1. Перейдите на [Google AI Studio](https://aistudio.google.com/).
2. Войдите под своим Google-аккаунтом.
3. Нажмите **«Get API key»** ➔ **«Create API key»**.
4. Скопируйте ключ вида: `AIzaSy...`.

### Шаг 2. Вставьте ключ в файл `.env`
Откройте файл `.env` в корне проекта и вставьте ваш ключ:
```env
GEMINI_API_KEY=AIzaSyВАШ_КЛЮЧ_СЮДА
```

### Шаг 3. Запустите бэкенд-сервер
В терминале выполните команду:
```powershell
python server.py
```

Сервер запустится на порту `8000`:
* Веб-платформа: `http://localhost:8000/`
* Проверка здоровья: `http://localhost:8000/api/health`
* Диалог с ИИ: `POST http://localhost:8000/api/ai/intake`
* Аналитика и отчеты: `POST http://localhost:8000/api/ai/analytics`

## Настройка параметров в `.env`

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | *(пусто)* | Секретный ключ Google Gemini API |
| `GEMINI_INTAKE_MODEL` | `gemini-1.5-flash` | Модель для диалога с сотрудником |
| `GEMINI_ANALYTICS_MODEL` | `gemini-1.5-pro` | Модель для аналитики и отчетов Правлению |
| `SERVER_PORT` | `8000` | Сетевой порт HTTP-сервера |
| `SERVER_HOST` | `0.0.0.0` | Сетевой интерфейс прослушивания |
